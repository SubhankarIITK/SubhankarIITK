## About me

I'm Subhankar, at IIT Kanpur. My projects span computer vision, machine learning, and scientific computing. I enjoy making the underlying methods visible through working code, visualizations, and results that can be checked.

## Selected projects

### [Random Walk Laboratory](https://github.com/SubhankarIITK/Random-Walker-)

An interactive laboratory for random walks in 1D–5D. Inspect ensemble members, explore coordinate projections, and watch MSD estimates and distributions build as walkers are included. Export the data to verify the results.

`Python` · `NumPy` · `SciPy` · `FastAPI` · `React` · `Three.js`

### [Object Detection in Drone Images](https://github.com/SubhankarIITK/Visual-Object-Search-in-Drone-Image)

Object detection on aerial imagery using YOLOv8 and the VisDrone dataset, with a dashboard for inference and inspecting detections.

`Python` · `PyTorch` · `YOLOv8` · `Streamlit`

### [Transformer from Scratch](https://github.com/SubhankarIITK/pytorch-transformer)

A PyTorch implementation of a Transformer for text generation, including attention, model layers, tokenization, training, and generation code.

`Python` · `PyTorch` · `Attention` · `Text generation`

### [Eye-Fatigue Classifier](https://github.com/SubhankarIITK/eye-fatigue-classifier)

A machine learning experiment using **synthetic eye-tracking data**, feature engineering, and classifier comparisons.

`Python` · `Feature engineering` · `Random Forest` · `SVM`
